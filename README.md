# myrdp

The Dola.com Windows browser-profile application is in [dola_profile_manager](dola_profile_manager/README.md).

It includes a Tkinter dashboard, independent persistent Edge/Chrome profiles, manual login helpers, cookie/state exports and imports, SQLite metadata, Windows setup scripts and automated tests. See [validation evidence](dola_profile_manager/VALIDATION.md) for executed checks and platform limitations.

The existing GitHub RDP workflow is preserved and was not executed during application development.
